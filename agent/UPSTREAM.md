# 来源与改动

运行基础来自 GOSIM 官方资源页的 Python 示例：
https://create.gosim.org/survey26/platform/downloads/examples/python.zip

上游仓库：https://github.com/gosimfoundation/hackathon-survey26/tree/main/examples/python

本次于 2026-10-05 下载。保留上游几何、公开评分配置、空间索引和时钟基础，
并按本项目审阅结果调整以下行为：

- 将两次相似的天气建议调用改为明确的“公告/预报解析 → 夜间任务规划”流程。
- 统一使用公开参数计算必做完成阈值及罚分；按模型受约束的优先级调整候选排序。
- 候选光纤和邻域搜索使用初始化下发的网格，避免隐藏卡上硬编码 4×4。
- 发送前严格验证类型、有限数值、未知字段和时间；异常动作清除待确认状态并安全回退。
- 模型请求具有每次、每问、累计实际等待时间和请求次数上限，失败自动降级。
- 本地测试覆盖真实反馈、数据丢失回滚、不同网格、恶意模型输出和仓库根清单独立启动。

上游示例许可证见 LICENSE.md。自研扩展与上游基础明确区分；不把官方示例作为全部原创成果。

2026-10-05 策略优化：

- 实际最佳得分和完成因子上下界分开维护，失效曝光同时回滚；每次曝光只贡献一个质量样本。
- 按上报反馈维护误报与修复状态，不再设置全季两次上限；需付罚分时使用更严格证据与冷却。
- 用线性边际得分联合比较候选视场、光纤目标、曝光时长和 program，加入阈值与夜末曝光候选。
- 限时请求按窗口内实际进度和可行性纳入调度，历史完成不能替代新窗口观测。
- 根据公开命中反馈标定固定指向偏移；搜索降档可恢复，模型计划按条件变化缓存。

当前本地验证与局限见根目录 STRATEGY_ZH.md。

2026-10-06 正式日志驱动优化：

- 单次决策共享几何与收益计算，调速同时使用 CPU 和实际时间预算；按近期夜间推进量估计剩余决策，区分搜索与一次性准备开销。
- 自研 exposure.py 按公开时段中点积分空气质量与月光；科学质量尺度和 program 匹配证据分别维护。
- 用真实科学增量检测收益停滞，临时降低普通目标权重；必做与请求目标继续参与规划，环境变化时清除冷却。
- 自研 requests.py 使用宽度 8 的束搜索检查未来窗口和并行光纤曝光，计入机会成本，单次曝光的请求规划收益不得重复超过一次奖励。
- DARK 证据按独立曝光记录匹配与未知；收费报告要求跨夜及充分匹配证据。
- 两阶段模型按成对预算执行，同条件下保留成功建议；预算不足时根据当前公开信息确定性更新。
- 增加可选诊断记录和不可变快照基准工具；本地输出、私有配置及官方引擎保持不入 Git。
